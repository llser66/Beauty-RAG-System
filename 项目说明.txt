Beauty Agent — 改造后的项目说明
================================

一、产品定位
------------

这是一个面向美妆护肤场景的 AI 知识助手。用户可以通过 RAG 或 Agent 模式询问成分、产品、护肤流程和内容创作问题，也可以上传皮肤照片进行非医疗性的初步分析。

二、核心功能
------------

1. RAG 模式
   - 从 Milvus 检索知识库文本；
   - 使用 BGE-Reranker 做二次排序；
   - 调用 DeepSeek-V3 生成回答；
   - 支持 SSE 流式回答、来源文件和相关图片。

2. Agent 模式
   - 使用 LangChain Agent 自主决定下一步操作；
   - 工具包括：搜索知识库、搜索图片、查看知识库统计、分析皮肤照片；
   - 支持最近 8 条对话历史；
   - 前端实时展示工具调用步骤和图片结果。

3. 知识库
   - 支持 TXT、PDF、DOCX、XLSX；
   - 自动解析和文本切片；
   - 支持新文件增量入库；
   - 替换同名文档时自动全量重建，避免旧向量残留；
   - 当前示例资料包括成分百科、产品库、小红书笔记和文案模板。

4. 图片能力
   - CLIP 图文向量检索；
   - 文本搜索本地产品/素材图片；
   - 对话图片上传后，由视觉模型调用 analyze_skin 工具；
   - 上传内容会经过大小、扩展名、图片格式和路径校验。

5. 界面和运维
   - Streamlit 奶油白、深梅紫、玫瑰金视觉主题；
   - Agent/RAG 模式切换；
   - 知识库统计、上传、索引重建；
   - 后端 `/health` 健康检查；
   - Docker Compose 启动 Milvus；
   - Windows `start.bat` 一键启动。

6. 隐私和伦理边界
   - 上传皮肤照片前必须确认本人或已获得照片本人授权；
   - 对话图片重新编码并清除 EXIF/GPS 元数据，默认 24 小时自动清理；
   - 对话图片读取和删除需要 Bearer Token，不再公开挂载静态目录；
   - 前端明确告知文本和图片可能发送到外部模型服务；
   - 对孕期、儿童、过敏、用药和紧急症状显示安全提醒，不进行疾病诊断或药物处方。

三、主要接口
------------

后端默认端口：8877。

   GET  /health
   POST /api/v1/rag/chat
   POST /api/v1/rag/chat/stream
   POST /api/v1/agent/chat
   POST /api/v1/agent/chat/stream
   POST /api/v1/chat/upload_image
   POST /api/v1/knowledge/upload
   POST /api/v1/knowledge/rebuild
   GET  /api/v1/knowledge/stats
   GET  /api/v1/privacy
   GET  /api/v1/chat/uploads/{file_id}
   DELETE /api/v1/chat/uploads/{file_id}

除 `/health` 和公开的 `/api/v1/privacy` 外的接口使用 Bearer Token 鉴权。Token 不再通过公开接口返回，前端从同一份 `.env` 读取。

图片分析只描述与护肤相关的可观察表现，不推断身份、年龄、种族、健康状态或“美丑”；遇到孕期、儿童、用药、过敏或严重症状时，应咨询医生或药师。

四、启动方式
------------

1. 复制 `.env.example` 为 `.env`，配置 SiliconFlow API Key；
2. 安装 `requirements.txt`；
3. 执行 `docker compose up -d`；
4. 双击 `start.bat`，或分别运行：

   uvicorn main:app --host 0.0.0.0 --port 8877
   streamlit run app_frontend.py

五、验证命令
------------

   pytest -q tests
   python -m py_compile main.py app_frontend.py agent\tools.py agent\orchestrator.py rebuild.py

外部模型 API、Milvus 和模型下载属于运行环境依赖，需要在真实部署环境中进一步联调。
