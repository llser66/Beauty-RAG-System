  Beauty Agent — 美妆护肤 AI 助手 · 项目文件说明
═══════════════════════════════════════════════════════════════

一、核心入口
───────────────────────────────────────────────────────────────

1. main.py
   后端主程序 — FastAPI 服务器
   - 提供 RAG 知识库检索 API（/api/v1/rag/*）
   - 提供 Agent 自主推理 API（/api/v1/agent/*）
   - 文档/图片上传、索引重建、知识库统计
   - 使用 DeepSeek-V3 作为 LLM，Qwen3-Embedding 做向量化
   - 启动方式：uvicorn main:app --host 0.0.0.0 --port 8001

2. app_frontend.py
   前端主程序 — Streamlit 交互界面
   - 深色主题，专业美观的聊天 UI
   - 支持两种对话模式：Agent 模式 / RAG 模式
   - Agent 模式显示"思考过程"面板（工具调用步骤）
   - 图片搜索结果以卡片网格展示
   - 侧边栏显示知识库统计、文件上传、索引管理
   - 启动方式：streamlit run app_frontend.py

3. start.bat
   Windows 一键启动脚本
   - 检测 .env 配置文件
   - 启动 Milvus 向量数据库（Docker）
   - 启动后端（端口 8001）
   - 启动前端（端口 8501）

4. requirements.txt
   Python 依赖清单
   - FastAPI / Uvicorn（后端框架）
   - LangChain 全家桶（RAG 流水线）
   - Milvus / PyMilvus（向量数据库）
   - Streamlit（前端）
   - PyMuPDF / python-docx / openpyxl（文档解析）
   - Transformers / Pillow（CLIP 多模态模型）


二、Agent 核心层（新增）
───────────────────────────────────────────────────────────────

5. agent/__init__.py
   Agent 包初始化文件，标识 agent/ 为 Python 包

6. agent/tools.py
   工具定义层 — 把 RAG 能力包装成 LLM 可调用的 Function Calling 工具
   - 定义 3 个工具：search_knowledge_base（搜知识库）
                               search_images（搜图片）
                               get_knowledge_base_stats（看统计）
   - 每个工具有 JSON Schema 定义（发给 LLM 的参数描述）
   - 每个工具有异步执行函数（实际调用后端能力）
   - 工具执行时支持依赖注入（text_store、rerank_func 等）
   - 使用 BGE-Reranker 对搜索结果精排

7. agent/orchestrator.py
   Agent 编排器 — ReAct（思考→行动→观察）主循环
   - 定义 Agent 的 System Prompt（角色、能力、行为准则）
   - run_agent()：非流式版，返回完整答案 + 步骤记录
   - run_agent_stream()：流式版，逐步 yield 事件
   - 循环逻辑：调用 LLM（带工具）→ 解析 tool_calls → 执行工具 → 放回消息 → 继续
   - 直到 LLM 认为信息足够，直接生成最终回答
   - 有最大迭代次数保护（默认 10 次，防死循环）


三、工具模块
───────────────────────────────────────────────────────────────

8. utils/document_loader.py
   多格式文档解析器
   - 支持 .txt / .pdf / .docx / .xlsx 四种格式
   - 自动识别文件扩展名并调用对应解析器
   - 返回 LangChain Document 对象列表

9. utils/multimodal.py
   多模态向量引擎 — CLIP 模型
   - embed_image()：图片 → 512 维向量
   - embed_text_for_image_search()：文本 → 512 维向量
   - 实现图文双路搜索（用文字搜图片）

10. utils/reranker.py
    BGE-Reranker 精细化重排引擎
    - 对 Milvus 粗召回结果进行深度相关性打分
    - 使用 BAAI/bge-reranker-v2-m3 交叉编码模型
    - 自动尝试 HuggingFace 镜像下载
    - 网络不通时降级为原始排序（不影响核心流程）

11. utils/auth.py
    API Token 鉴权模块
    - Bearer Token 方式验证 API 请求
    - 自动生成 Token（secrets.token_hex）
    - 自动写入 .env 文件

12. docker-compose.yml

───────────────────────────────────────────────────────────────

  架构说明
═══════════════════════════════════════════════════════════════

传统 RAG 模式：
  用户 → 搜索知识库 → 重排 → LLM 生成 → 回答

Agent 模式（本次新增）：
  用户 → LLM 分析意图 → 决定调用工具
       ↘ 搜索知识库 → 观察结果 → 继续推理
       ↘ 搜索图片   → 观察结果 → 继续推理
       ↘ 查看统计   → 观察结果 → 继续推理
       → 综合所有信息 → 生成最终回答

Agent 的核心优势：
  - 可以多次调用不同工具获取多维度信息
  - 可以观察工具返回结果后决定下一步行动
  - 回答更全面、更有条理
  - 可扩展性强（加新工具只需在 tools.py 注册）
